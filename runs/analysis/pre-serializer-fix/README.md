# Measurements taken before the serializer fix

Every number in this directory was produced by replaying recorded corpora, which
were written before `fuzzer/campaign.py` learned to preserve raw-byte
surrogateescape sentinels (docs/design-decisions.md D13). Those corpora do not
contain the documents their strategies describe: across 10,000 historical inputs
there is not one raw UTF-16 byte-order mark.

These files are kept because `docs/comparison.md` explains why the result
changed. They are historical measurements, not the current results.
The current measurements are in `../coverage_trials.json`, regenerated by
`scripts/coverage_trials.py`, which re-runs each strategy rather than replaying
its recorded bytes.
